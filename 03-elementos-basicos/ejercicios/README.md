# Ejercicios: Elementos básicos

1. Declará una variable `temperatura` de tipo `float64` con valor `36.5`
   y una constante `Congelacion` con valor `0`. Mostralas por pantalla.
   → `01-temperatura/`

2. Escribí un programa que dado un número entero, imprima si es positivo,
   negativo o cero.
   → `02-positivo-negativo/`

3. Usando un `switch` sin expresión, escribí un programa que dado un
   número del 1 al 7, imprima el día de la semana correspondiente
   (1 = lunes, 7 = domingo).
   → `03-dia-semana/`

4. Usando un ciclo `for`, calculá la suma de los números del 1 al 100
   e imprimí el resultado.
   → `04-suma-1-100/`

5. Dado un slice de enteros `[]int{3, 7, 2, 9, 5}`, usá `range` para
   encontrar e imprimir el valor máximo.
   → `05-maximo/`
