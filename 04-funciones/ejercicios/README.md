# Ejercicios: Funciones

1. Escribí una función variádica `promedio` que reciba `nums ...float64`
   y devuelva el promedio. Si no recibe argumentos, debe devolver `0.0`.
   → `promedio/`

2. Escribí una función `aplicar` que reciba un slice de enteros y una
   función `f func(int) int`, y devuelva un nuevo slice con `f` aplicada
   a cada elemento.
   → `aplicar/`
