# Ejercicios: Funciones

## 01 - Promedio variádico

Completar la función `Promedio` en `01-promedio/promedio.go`.
Recibe `nums ...float64` y devuelve el promedio. Si no recibe argumentos,
debe devolver `0.0`.

→ `01-promedio/`

## 02 - Aplicar función a slice

Completar la función `Aplicar` en `02-aplicar/aplicar.go`.
Recibe un slice de enteros y una función `f func(int) int`, y devuelve
un nuevo slice con `f` aplicada a cada elemento.

→ `02-aplicar/`
