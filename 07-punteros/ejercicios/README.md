# Ejercicios: Punteros

1. Escribí una función `swap` que intercambie los valores de dos
   variables enteras usando punteros.
   → `swap/`

2. Escribí una función `sumarPunteros` que reciba dos punteros a enteros
   (`*int`) y devuelva la suma de los valores apuntados. Si alguno es
   `nil`, debe tratarlo como `0`.
   → `sumar-punteros/`

3. Escribí una función `dividir` que reciba un dividendo y un divisor
   (enteros), y devuelva el cociente como valor de retorno y el resto a
   través de un parámetro puntero `*int`.
   → `dividir/`

4. Escribí una función `inicializarArreglo` que reciba un puntero a un
   arreglo `[5]int` y lo inicialice con los valores `0, 2, 4, 6, 8`
   (el doble de cada índice).
   → `inicializar-arreglo/`

5. Escribí una función `Concatenar` que reciba un puntero a `string`
   y un sufijo, y modifique el string original agregándole el sufijo.
   → `concatenar/`
