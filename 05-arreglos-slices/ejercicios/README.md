# Ejercicios: Arreglos y slices

## 01 - Invertir slice

Completar la función `Invertir` en `01-invertir/invertir.go`.
Invierte un slice in place. Ejemplo: `[1, 2, 3, 4]` → `[4, 3, 2, 1]`.

→ `01-invertir/`

## 02 - Rotar slice

Completar la función `Rotar` en `02-rotar/rotar.go`.
Rota un slice en `k` posiciones. Ejemplo: `[1, 2, 3, 4, 5]` rotado en 2
→ `[3, 4, 5, 1, 2]`. Reutiliza la función `Invertir` del ejercicio anterior.

→ `02-rotar/`

## 03 - Eliminar elemento

Completar la función `Eliminar` en `03-eliminar/eliminar.go`.
Elimina el elemento en la posición `pos` de un slice y devuelve el nuevo
slice. Ejemplo: `[1, 2, 3, 4, 5]`, posición 2 → `[1, 2, 4, 5]`.

→ `03-eliminar/`

## 04 - Eliminar duplicados

Completar la función `EliminarDuplicados` en
`04-eliminar-duplicados/eliminar_duplicados.go`.
Devuelve un nuevo slice sin elementos duplicados, preservando el orden.
Ejemplo: `[1, 2, 2, 3, 4, 4, 5]` → `[1, 2, 3, 4, 5]`.

→ `04-eliminar-duplicados/`
