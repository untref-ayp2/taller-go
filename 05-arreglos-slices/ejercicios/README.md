# Ejercicios: Arreglos y slices

1. Escribí una función `invertir` que invierta un slice. Por ejemplo,
   el slice `[1, 2, 3, 4]` invertido sería `[4, 3, 2, 1]`.
   → `invertir/`

2. Escribí una función `rotar` que rote un slice en un número `n` de
   posiciones. Por ejemplo, el slice `[1, 2, 3, 4, 5]` rotado en 2
   posiciones sería `[3, 4, 5, 1, 2]`.
   → `rotar/`

3. Escribí una función `eliminar` que elimine un elemento de un slice.
   Por ejemplo, el slice `[1, 2, 3, 4, 5]` eliminando el elemento en
   la posición 2 sería `[1, 2, 4, 5]`.
   → `eliminar/`

4. Escribí una función `eliminarDuplicados` que elimine los elementos
   duplicados de un slice. Por ejemplo, el slice `[1, 2, 2, 3, 4, 4, 5]`
   sin duplicados sería `[1, 2, 3, 4, 5]`.
   → `eliminar-duplicados/`
