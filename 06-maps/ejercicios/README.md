# Ejercicios: Maps

## 01 - Contar palabras

Completar la función `ContarPalabras` en `01-contar-palabras/contar_palabras.go`.
Recibe un string y devuelve un `map[string]int` con la frecuencia de cada palabra.
La función `strings.Split` puede ser útil.

→ `01-contar-palabras/`

## 02 - Comparar mapas

Completar la función `Igual` en `02-igual/igual.go`.
Compara dos `map[string]int` y devuelve `true` si tienen las mismas claves
y los mismos valores. Prototipo: `func Igual(x, y map[string]int) bool`.

→ `02-igual/`

## 03 - Anagramas

Completar la función `SonAnagramas` en `03-anagramas/anagramas.go`.
Dos strings son anagramas si tienen las mismas letras en diferente orden.
Prototipo: `func SonAnagramas(s1, s2 string) bool`. Complejidad esperada: $O(n)$.

→ `03-anagramas/`
