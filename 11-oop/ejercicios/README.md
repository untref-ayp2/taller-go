# Ejercicios: Programación orientada a objetos

## 01 - Sistema de empleados

Completar la implementación en `01-sistema-empleados/empleados/`.
Hay que implementar los structs `TiempoCompleto`, `MedioTiempo`, `PorComision`
y `Gerente` (con embedding de `TiempoCompleto`), todos satisfaciendo la
interfaz `Empleado`. En `main.go`, completar las funciones `TotalSueldos`
y `EmpleadoConMasResponsabilidad`.
